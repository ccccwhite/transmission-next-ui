基于上游 v0.3.4 的 Fork 增强版本。

## 更新

- 修复 Transmission 原生字符串标签兼容问题，兼容旧 JSON 包装标签。
- 左侧增加标签、Tracker、目录筛选、数量统计和错误筛选。
- 列表及卡片支持右键操作，支持批量选择。
- 记住上次的筛选、排序、视图和页面状态。
- 标签支持已有标签下拉搜索、多选、新建，同时显示当前标签及批量标签分布。
- 设置保存位置支持可选的完成后校验；校验时显示真实校验进度。
- Fork 说明迁移至 docs/FORK.md 和 docs/FORK_EN.md。

## 安装

下载下面的 **release.zip**，解压后将其中的静态文件部署到自定义 WebUI 目录。无需下载 Source code，也无需自行构建。

LinuxServer Transmission 容器可将宿主机 WebUI 目录映射到 `/webui`，设置 `TRANSMISSION_WEB_HOME=/webui`。仅替换静态页面文件，不覆盖 `/config` 和下载数据；保留已挂载的根目录。

## 验证与限制

80 项测试、TypeScript 检查及生产构建通过。完整版本使用模拟 RPC 验证界面；原生标签追加曾在 Unraid 6.12.13 + LinuxServer Transmission 4.1.3 测试种子上验证。本次未部署到 NAS。
